BlueMath admin inbox: Render environment variables

Required:
ADMIN_USERNAME=choose-your-private-admin-username
ADMIN_PASSWORD=choose-a-long-unique-password
SECRET_KEY=generate-a-long-random-secret-and-keep-it-private
COOKIE_SECURE=true
DATABASE_URL=your-managed-PostgreSQL-connection-URL

Do not put real secrets in this file or commit them to GitHub. Add these values under Render Dashboard > your BlueMath Web Service > Environment.

Important: DATABASE_URL must point to a persistent PostgreSQL database. Without it, the app uses a local SQLite file, which is fine for local development but may be lost on Render's ephemeral filesystem after a restart or redeploy.

Admin inbox URL: https://YOUR-SITE.onrender.com/admin
Build command: pip install -r requirements.txt
Start command: gunicorn app:app
